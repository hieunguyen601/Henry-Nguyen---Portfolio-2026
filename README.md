# Henry Hieu Nguyen — Developer Portfolio

Personal portfolio site built from scratch with vanilla HTML, CSS, and JavaScript.

---

## Pages

| Page | Description |
|------|-------------|
| `mainPage.html` | Home — intro, skills, projects, Spotify, contact |
| `experiencePage.html` | Work experience timeline |
| `educationPage.html` | Education history |
| `activitiesPage.html` | Photo gallery / activities |
| `404.html` | Custom 404 page |

---

## Features

- Dark / light mode with `localStorage` persistence
- Spotify live data (recently played, top tracks) via serverless function
- Project cards with hover overlays and Live / Code links
- Project filtering by tech stack
- Scroll reveal animations
- Animated stats counter
- Scroll progress bar
- Back to top button
- Working contact form
- Resume download
- Page transition animations
- Fully responsive (mobile, tablet, desktop)

---

## Tech Stack

- HTML5, CSS3, JavaScript (no frameworks)
- Spotify Web API (refresh token flow)
- Formspree (contact form)
